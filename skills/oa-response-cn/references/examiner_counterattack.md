# 审查员视角二次攻击与论证修订（v0.2）

## 目标
强制验证“当前拟修改权利要求1 + 创造性论证”是否能够抵御审查员合乎证据的下一轮攻击。不能通过虚构不利证据制造假风险，也不能以模型自我反驳替代真实证据核查。

## 测试路径
1. **公开事实攻击**：某区别其实被D1明示/隐含公开？OA指出的D1段落是否未被充分解释？
2. **组合攻击**：D1+D2/D3+常识能否得到完整流程？尽可能搭建具体组合，不只列名词。
3. **常规选择攻击**：已知抽象思想与权项具体数据关系之间还差什么，是否有证据缺口？
4. **替代实现攻击**：若D1有不需该区别即可解决同一问题的方式，是否影响动机与显而易见判断？
5. **技术效果攻击**：有没有仅出现在从权、个别实施例或无数据支持的效果？
6. **超范围与清楚性攻击**：新增特征的组合支持、符号关系、引用范围、数值条件及独权与装置对应是否成立？
7. **版本攻击**：论证的修改后权项是否与最后确认的替换页**逐字一致**？

## 输出格式
|审查员可提出的最强观点|基于哪份真实原文|对当前论点的威胁|可以完善的证据/分析|是否必须修改权项|
|---|---|---|---|---|

优先修补最强证据缺口，删除不成立的辅助论点。修改权项需要返回“阶段3”请用户重新确认，不能直接改写并宣称最终版。
