# OA材料核验与办案状态机（v0.2）

## 输入清单
| 类型 | 必需性 | 核查内容 |
|---|---|---|
| 本次OA全文 | 必需 | OA次数、发文日、所有驳回/缺陷观点、所涉权项、法律理由、附件与期限 |
| 当前有效权利要求 | 必需 | 最新生效版本、正文、全部从属引用、独立权利要求编号；不可仅以旧申请公布权项代替 |
| 原始申请说明书及权利要求、附图 | 修改时必需 | 初始提交日期、原始记载的具体支持；公布文本相同需有证据或用户明确说明 |
| D1—Dn全文 | 创造性分析必需 | 公开日、申请/优先权、原始段落与附图；仅有OA摘要时标未核实 |
| 既往OA、答复、对照页、替换页 | OA2/多通时必需 | 各轮技术差异、争议演变与编号改变 |
| 用户的客户策略与办案限制 | 视情况 | 最重视保护范围、授权时间、权利要求类别、是否优先争辩 |

## 文档读取检查
- Word：实际抽取正文、表格、权要编号、页眉页脚；旧`.doc`需要可靠转换，不能只根据名字认为已读取。
- PDF：提取文字并抽样核对段落、表格、附图；扫描页另做图像检视。文字层缺失需明确指出。
- 图像：查看原图清晰度及不确定字迹；人工整理内容与补充内容分别标注。
- 引证全文缺失时不得作“D1未公开”的绝对结论。

## 状态闸门
- G0：未获得足够材料时，仅输出材料表与阻断项，不出正式结论。
- G1：OA攻击逻辑及对比证据核实后，才进行策略选择；用户确认。
- G2：拟修改的权利要求文本、范围代价、逐项原始依据经用户确认，才形成正式创造性论证稿。
- G3：正式正文经用户确认，才生成Word。
- G4：排版、编号、对照页、实体与法律条文核查完成，才可标“待专业人员最终审阅”，不可自行标“已提交/已授权”。

## 阶段成果
0 材料表和版本台账 → 1 OA争议矩阵与逐特征表 → 2 候选策略比较 → 3 修改对照与依据 → 4 创造性论证框架 → 5 正式正文 → 6 Word及内部检查记录。

## OA2专门要求
创建“前次审查意见原话—前次意见/修改的答复—本次OA针对性评价—未解决争点—新证据与候选修正”的表格。OA2并不自动表示第一次答复失败或错误。
