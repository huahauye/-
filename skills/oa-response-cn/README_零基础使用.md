# oa-response-cn v0.2｜零代码入门

## 你现在拿到的是什么
一套可安装、可重复运行的中国发明专利OA答复**Skill文件夹**，不是已经独立运行的网站，也不代表自动通过审查。`SKILL.md`是主指令，`references/`是详细规则，`assets/`是模板，`tests/`是测试方案，`scripts/`是可选的小工具。

## 用Codex
1. 下载并解压`oa-response-cn-v0.2.zip`，解压后确认里面有完整的`oa-response-cn/`文件夹，而不是只有单个`SKILL.md`。
2. 打开Codex，要求它帮你安装以下Skill。**把整个Skill文件夹交给Codex，别只复制SKILL.md。**
3. 复制下面指令：
   > 请将我提供的`oa-response-cn`文件夹安装为个人可调用的Codex Skill。先检查SKILL.md的YAML frontmatter和相对引用路径是否完整，并确认当前Codex版本支持的Skill安装目录。不要修改业务规则。安装后告诉我如何在新聊天里调用`$oa-response-cn`，然后仅用T00、T01做安全冒烟测试。不要上传任何客户原始文件到公开GitHub。
4. 打开新任务，按`assets/prompts_使用示例.md`先做阶段0，检查触发效果。如Codex不支持某个目录位置，让Codex依据其已安装版本检查有效位置，**不要盲目创建一个它不会读取的目录**。

## 直接在普通ChatGPT里使用
- 可以建立一个**私有项目**，上传Skill的主控说明、相关references与必要的模板；在项目指令中写“按SKILL.md阶段执行，遇到重要节点等待我确认”。
- 这属于**基于项目文件复用Skill规则**，不等于普通聊天页面自动安装和触发了Codex Skill；两者能力和可访问文件方式不同。
- 新OA一开始只给OA及原申请、当前有效权要和必要对比文献；分阶段运行，先让你确认策略，不建议让模型一次性直出正式Word。

## Word
包中的`assets/意见陈述书正文_空白模板.docx`为**演示用可编辑内容模板，不是国知局行政表格，也不是可不经检查直接提交的文书**。只有确认正文和替换权要后再套用户真实模板。

## 数据和保密
- 真实案卷复盘（含案卷编号、申请名称和内部复盘信息）**不随仓库分发**：需要时放在 `skills/private/` 或 `references/case_*.md`，这些路径已在 `.gitignore` 中排除，不要提交到公共仓库。
- `references/mairui_decision_tree.md`标记了原图歧义，必须结合证据及当时适用法律，不能当作强制法律条文。
- 包内不包含原申请/D1—Dn PDF或三份优秀案例的**完整原始Word**；以后新案仍须提供其案卷材料。

## v0.2范围
已包含：材料核验、创三步法、迈瑞P0—P6、权要修改、审查员反向攻击、正文风格、基础Word模板、测试评分和简单QA脚本。
未包含：自动提交、真实授权概率预测、完整法规全文库、自动消除所有修改超范围风险、经验证的跨案件稳定授权表现。
